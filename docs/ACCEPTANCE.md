# Local demo scope

EUR sample catalogue, three languages, browser favourites, comparison and condition diagrams. Listing drafts and demo viewing requests use signed browser sessions and D1 ownership filters. Demo sessions are localhost-only and expire after 24 hours or server restart. No real accounts, public publication, seller messaging, uploads or payments.

Run `npm run check`, `npm test`, `npm run db:setup`, `npm run test:api` and `npm run build`.
