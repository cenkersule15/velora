# VELORA 0.1.2 — EUR catalogue and SUVs

- Catalogue, comparison, budgets and new listing drafts use EUR.
- Sample prices are curated demo amounts, not live currency conversions or real market offers.
- Added Mercedes-Benz G 63 AMG (G-Class) and Land Rover Defender 110 with locally hosted Unsplash photographs.
- SUV body filters, deduplicated make selectors and catalogue counters reflect eight listings.
- Text budgets support euro symbols, EUR/euro, k, bin/tausend/thousand and European thousands separators.
- New draft payloads record currency explicitly as EUR. Existing records lacking a currency field were created in TRY and retain that label; no stored amount is silently reinterpreted.
- The update preserves database files, favourites and user records.
