# Uygulama ekran görüntüleri

README'deki mevcut kapak bir otomobil fotoğrafıdır. Gerçek arayüz ekran görüntülerini diline göre eklemek için:

1. Uygulamayı açıp ilgili dili seç.
2. Katalog ve euro fiyatları görünecek şekilde ekran görüntüsü al.
3. Dosyaları `docs/screenshots/` altına kaydet.

| README | Önerilen dosya |
|---|---|
| README.md | docs/screenshots/discover-en.png |
| README.de.md | docs/screenshots/discover-de.png |
| README.tr.md | docs/screenshots/discover-tr.png |

İlgili görseli kaydettikten sonra README'ye eklenebilecek satırlar:

```md
![VELORA — Discover](docs/screenshots/discover-en.png)
![VELORA — Entdecken](docs/screenshots/discover-de.png)
![VELORA — Keşfet](docs/screenshots/discover-tr.png)
```

Her README için yalnızca ilgili dilin satırını kullan. Henüz olmayan dosyalara görsel bağlantısı ekleme. Kişisel bilgi içeren ekran görüntüsü paylaşma.
